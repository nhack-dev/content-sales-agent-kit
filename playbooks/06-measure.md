# 06 測る・1か所だけ直す（毎週）

## 数字の集め方（1週1行・data/funnel.csv）

| 列 | どこで数えるか |
|---|---|
| impressions | 各SNSのキットの数字（表示回数）を足す |
| profile_clicks | 各SNSのプロフィールへの移動・リンクのクリック（取れるものだけ） |
| line_adds | line-agent-kit の `admin.py stats` の友だちの増え |
| offer_clicks | Stripe の決済リンクの表示・販売サービスのページの閲覧 |
| purchases・revenue・refunds | Stripe／販売サービスの売上（返金は別に） |
| blocks | line-agent-kit の `admin.py stats` のブロックの増え |

取れない数字は空のまま（推測で埋めない）。

## 手順

```bash
python3 scripts/funnel_report.py data/funnel.csv --last 8
```

1. 「いちばん落ちた段」と「まず見るところ」を読む
2. その段の **1か所だけ** を変える案を出す（例：受け取るものの名前・5日目の便の1行目・販売ページの見出し）
3. オーナーの OK → 変える → 翌週に同じ表で前→後を比べる
4. 効いたら残す・効かなければ戻す。どちらでも1行で記録する（日付・変えた所・前→後）

## 見方のこつ

- 1週の人数が少ないときは、率が大きく揺れる。2週続けて落ちたら直す
- 売上より先に、ブロックの率と返金を見る（無理な売り方の合図）
