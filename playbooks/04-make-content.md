# 04 教材を作る（PDF・note・動画台本）

## 手順

1. `products/<id>/outline.md`（kind ごとの型）の目次を、brief.md の「1週間後にできること」から逆に組む
2. 目次をオーナーに見せて OK を取ってから本文を書く
3. 1章ずつ書き、各章の終わりに「この章でやること1つ」を置く
4. 書き終えたら、brief.md の約束を1行ずつ目次と照らす（約束したのに書いていない所を0にする）
5. `python3 scripts/claim_check.py products/<id>/` をかける

## 形ごとの決まり

### PDF
- 1ページに伝えることは1つ・図か表を1つ・本文12pt以上・スマホで読める大きさ
- 目次にリンク。奥付に版（v1.0 など）・作った人・問い合わせ先
- PDF にする道具はオーナーの手元のもの（文書作成ソフトの書き出しなど）。このキットは文章と構成を作る

### note の有料記事
- 無料の部分で、何が書いてあるか（見出し全部）と値段・返金の扱いを見せる
- 無料の部分で約束したことを、有料の部分で必ず渡す
- note の利用規約・ガイドラインを公式で確かめる（禁止の内容・返金の扱い）

### 動画（台本）
- 1本 5〜10分・手順は3つまで・字幕あり
- 画面に個人の情報（メール・名前・管理画面の数字）を映さない。映るならぼかす
- 撮る・編集する道具はオーナーの手元のもの。このキットは台本と構成を作る

## 体験談・数字

- 本人の許可・出どころ（いつ・どこで・どの条件）を残す。許可の記録が無いものは使わない
- 架空の例は「例」と書く。実在の人・会社の名前を例に使わない
